One-time setup

Drag this button onto your bookmarks bar:

⚔ Import to Deepwoken

Bookmarks bar hidden? Press Ctrl+Shift+B (⌘+Shift+B on Mac). On a phone this doesn't work — use a computer.

Then, for any build
  1. Click Send to deepwoken.co above — it copies the build and opens the builder.
  2. In the builder tab, click the ⚔ Import to Deepwoken bookmark. The build loads instantly.

If the bookmark can't read your clipboard it asks you to paste — the code is also in the box below.
